## Para quién es

Para quien ya hace componentes con React y usa Tailwind, y quiere dejar de pelearse con lo que "debería funcionar y no funciona": la regla que no se aplica, la tarjeta que desborda en móvil, la paleta que no se puede cambiar.

Si todavía estás con las bases de CSS (la caja, grid, los temas, los estados de un botón), empieza por la ruta hermana [CSS y Tailwind, de las bases a interfaces reales](/rutas/css-y-tailwind).

## Qué vas a poder hacer al terminar

```mindmap
Al terminar la ruta
- Estructura :: un proyecto que crece sin desordenarse
- React :: idiomas, datos y eventos
  - interfaz bilingüe sin librerías
  - fetch con errores y tiempo límite
  - debounce y throttle
- CSS :: entender la cascada
  - capas y especificidad
  - tokens y variables
- Verificar :: con capturas reales
  - anchos y temas
  - desbordes
```

## Cómo seguirla

Después de la estructura y los idiomas, dos guías de JavaScript cubren lo que más falla en una interfaz real: pedir datos (errores y tiempo límite) y escuchar eventos rápidos (debounce y throttle). Luego, la guía de capas y tokens prepara los **tres retos** del Laboratorio. En cada reto, primero mira el error con «Sin arreglo», intenta explicar por qué pasa y después compruébalo con «Con arreglo». La última guía te enseña a encontrar este tipo de errores por tu cuenta, antes de que los vea alguien más.
