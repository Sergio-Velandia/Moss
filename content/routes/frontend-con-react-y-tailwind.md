## Para quién es

Para quien ya hace componentes con React y usa Tailwind, y quiere dejar de pelearse con lo que "debería funcionar y no funciona": la regla que no se aplica, la tarjeta que desborda en móvil, la paleta que no se puede cambiar.

## Qué vas a poder hacer al terminar

```mindmap
Al terminar la ruta
- Estructura :: un proyecto que crece sin desordenarse
- Idiomas :: interfaz bilingüe sin librerías
- CSS :: entender la cascada
  - capas y especificidad
  - tokens y variables
- Verificar :: con capturas reales
  - anchos y temas
  - desbordes
```

## Cómo seguirla

Las tres guías centrales preparan los **tres retos** del Laboratorio. En cada reto, primero mira el error con «Sin arreglo», intenta explicar por qué pasa y después compruébalo con «Con arreglo». La última guía te enseña a encontrar este tipo de errores por tu cuenta, antes de que los vea alguien más.
