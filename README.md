# 🌱 Moss — Digital Garden

Mi "segundo cerebro" técnico: una biblioteca personal y visual donde guardo, documento, pruebo y reutilizo snippets, componentes, guías y artículos.

> El conocimiento técnico no debería quedarse enterrado; debería ser fácil de encontrar, entender, probar, conectar y reutilizar.

## Los cuatro pilares

- **El Laboratorio** — componentes UI y snippets con vista previa en vivo y código copiable.
- **El Manual** — documentación, configuraciones y guías.
- **La Bitácora** — blog técnico, aprendizajes y decisiones.
- **El Herbario** — búsqueda global sobre todo el contenido.

## Stack

React · Vite · TypeScript · Tailwind CSS · React Router · Motion · Lucide.
El contenido vive en archivos locales Markdown/MDX dentro de `content/`, versionados con Git. Sin base de datos ni backend.

## Empezar

```bash
npm install
npm run dev
```

## Estructura

```
content/   # Markdown/MDX: lab, manual, journal
src/       # Aplicación React
public/    # Archivos estáticos
```

## Seguridad

Este repositorio es público. No se guardan claves reales: usa variables de entorno (`.env`, ignorado por Git) y valores ficticios en los ejemplos. Ver `.env.example`.
